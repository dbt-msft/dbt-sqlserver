Fix a failed column widening permanently breaking the model. `alter_column_type`'s four-step rewrite (add `<col>__dbt_alter`, copy, drop the original, rename) commits each step on its own, so a run that failed part way, such as on a full tempdb, left `<col>__dbt_alter` behind and every later run failed on Msg 2705 until the column was dropped by hand. It now drops a leftover `<col>__dbt_alter` before starting, as long as the original column still exists.
