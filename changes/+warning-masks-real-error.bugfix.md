Stop reporting a SQL Server warning as the reason a model failed. When warning 8153, *Null value is eliminated by an aggregate*, and an error are both raised inside a nested batch - `EXEC()`, `sp_executesql` or a stored procedure - `pyodbc` and `mssql-python` raise only the warning and discard the error. The adapter now says the real error was masked and how to find it, and still includes the warning text.
