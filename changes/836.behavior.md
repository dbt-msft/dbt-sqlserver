`prefer_single_alter_column` now defaults to unset, which widens a column within its type (a longer `varchar`, or `varchar(max)`) with a single `ALTER COLUMN` instead of the four-step rewrite. On SQL Server 2022 that widening is metadata-only (instant on a 2M-row table, against 13 s for the rewrite), atomic, and keeps the column's indexes, default constraint and position, where the rewrite fails on an indexed or defaulted column and moves the column to the end. Other type changes still use the rewrite. Set `prefer_single_alter_column: false` to keep the rewrite for widening too.
